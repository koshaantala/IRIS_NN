# 🌸 Iris Neural Network Classifier — TensorFlow/Keras

A **TensorFlow/Keras-based neural network** that classifies Iris flower species with ~98% accuracy.  
Implements two hidden layers, visualizes training results, and generates a confusion matrix to evaluate performance.

---

## 🚀 Features
- Trains a multi-layer neural network using **TensorFlow/Keras**
- Achieves **~98% test accuracy** on the Iris dataset
- Visualizes **training/validation loss and accuracy**
- Generates a **confusion matrix** to assess model predictions
- Saves trained model as `.keras` for reuse or deployment
